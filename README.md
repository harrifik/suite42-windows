# Suite42 для Windows 11 (Rust)

Порт [sfzorin/kit42](https://github.com/sfzorin/kit42) — шести офисных приложений macOS — на Rust для Windows 11.
Интерфейс на русском и английском (язык системы, переключение в «Справка → Язык»).

| Приложение | Что делает | Форматы |
|---|---|---|
| **PDF42** | просмотр и правка PDF: страницы, аннотации, формы, закладки, вложения, водяные знаки, нумерация, Bates, редактирование (redaction), сжатие, защита, OCR, сравнение, подписи и печати | PDF |
| **DOC42** | текстовый редактор со стилями, списками, таблицами, рисунками, оглавлением | DOCX, DOC (чтение), ODT, RTF, HTML, Markdown, TXT, экспорт в PDF |
| **XLS42** | электронные таблицы: ~250 функций, динамические массивы, форматы чисел, диаграммы, объединение ячеек | XLSX, XLS (чтение), ODS, CSV, экспорт в PDF |
| **IMG42** | просмотр и правка изображений: коррекция, обрезка, удаление фона, разметка, Live Text (OCR) | PNG, JPEG, GIF, BMP, TIFF, WebP, HEIC (через Windows), SVG, PDF |
| **PPT42** | презентации: фигуры, таблицы, рисунки, темы, макеты, анимации, переходы, заметки, показ с пером и лазерной указкой | PPTX, POTX, ODP, OTP, экспорт в PDF/PNG/JPEG/Markdown |
| **SCN42** | сканирование (WIA/WinRT): обрезка, выравнивание, отбеливание, удаление пустых страниц, OCR | PDF, PDF/A, TIFF, JPEG, PNG, RTF |

Общая библиотека `crates/kit42` содержит:

- оформление в стиле Windows 11, диалоги и локализацию;
- генератор PDF со встроенными шрифтами;
- чтение и запись OOXML;
- редактор форматированного текста;
- библиотеку подписей и печатей;
- обёртки WinRT для рендеринга PDF, OCR, декодирования изображений и сканеров.

## Сборка

Нужен Rust (MSVC), например `winget install Rustlang.Rustup`.

```bash
cargo build --release
```

Готовые программы: `target\release\pdf42.exe`, `doc42.exe`, `xls42.exe`, `img42.exe`, `ppt42.exe`, `scn42.exe`.

## Командная строка

Каждое приложение принимает файлы для открытия, а также служебные команды, например:

```text
pdf42 --merge a.pdf b.pdf out.pdf      pdf42 --ocr scan.pdf out.pdf
pdf42 --lines in.pdf 1                 pdf42 --replace-text in.pdf out.pdf "старый" "новый" [страница]
pdf42 --images in.pdf                  pdf42 --image-op in.pdf out.pdf 2 1 move 50 0 | scale 0.5 | delete | replace pic.png
doc42 --convert in.docx out.pdf        xls42 --convert in.xlsx out.ods
xls42 --eval "=SUM(1,2,3)"             img42 --info photo.jpg
ppt42 --convert in.pptx out.pdf        ppt42 --export in.pptx folder\
scn42 --process in.png out.pdf
```

## Ограничения

- Нет цифровых подписей PDF (PAdES).
- Правка текста в PDF (инструмент «Правка текста», Ctrl+E) идёт построчно. Исходные символы удаляются из страницы, а новый текст печатается подобранным шрифтом того же размера и цвета. На сканах строка распознаётся через OCR Windows и закрашивается цветом фона, поэтому ошибки распознавания переходят в новый текст. Повёрнутый и вертикальный текст не редактируется.
- Шрифты встраиваются в PDF без подмножеств, поэтому файлы получаются крупнее.
- DOC42 не поддерживает рецензирование, примечания и сноски.
- PPT42 не читает старый формат `.ppt`.
